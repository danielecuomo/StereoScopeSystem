Red Viper SMS
=============

A Nintendo 3DS Sega Master System port based on the Red Viper project structure and the Gearsystem emulator core.

ROM files must use the `.sms` extension. The built-in file browser starts at `sdmc:/`.

Controls:
- D-pad: directions
- A/B: SMS buttons 1/2
- START: Start
- SELECT: exit

See `SMS_PORT.md` for build and ROM-loading notes.
